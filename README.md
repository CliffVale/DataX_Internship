# DataX Labs - Task 3: Interactive Dashboard Design

## Objective
Design an interactive dashboard for business stakeholders to inform business decisions.

## Tools Used
* Tableau Public (Web Authoring)
* PowerPoint

## Deliverables Included
* **Interactive Dashboard:** Built with key KPI cards (Sales, Profit), a time-series trend line, and interactive region slicers.
* **PPT Summary:** A presentation highlighting high-level KPIs, growth trajectories, and profitability outliers.
* **Dataset:** Sample - Superstore.csv
